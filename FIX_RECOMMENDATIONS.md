### Solusi 1: Migrasi SQL Tabel `advertisements` (Memperbaiki BUG-001 & BUG-002)
Jalankan skrip migrasi berikut pada SQL Editor di Supabase Dashboard untuk mengatasi error 503 pada Manajemen Iklan:

```sql
-- Migrasi Tabel Advertisements
CREATE TABLE IF NOT EXISTS public.advertisements (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title text NOT NULL CHECK (char_length(title) BETWEEN 3 AND 150),
    image_url text NOT NULL,
    target_url text NOT NULL,
    platform text NOT NULL DEFAULT 'Website',
    ad_type text NOT NULL DEFAULT 'Banner',
    position text NOT NULL DEFAULT 'Top',
    start_date date NOT NULL,
    end_date date NOT NULL,
    is_active boolean NOT NULL DEFAULT true,
    impressions bigint NOT NULL DEFAULT 0,
    clicks bigint NOT NULL DEFAULT 0,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now()
);

-- Kebijakan Row Level Security (RLS)
ALTER TABLE public.advertisements ENABLE ROW LEVEL SECURITY;

-- Publik & Tamu dapat melihat iklan aktif
CREATE POLICY "Public can view active ads"
    ON public.advertisements FOR SELECT
    TO anon, authenticated
    USING (is_active = true AND CURRENT_DATE BETWEEN start_date AND end_date);

-- Staf Admin dapat mengelola semua iklan
CREATE POLICY "Staff can manage all advertisements"
    ON public.advertisements FOR ALL
    TO authenticated
    USING (public.is_app_staff())
    WITH CHECK (public.is_app_staff());
```

### Solusi 2: Tambahkan Endpoint Mutasi Iklan pada Backend FastAPI
Tambahkan handler `POST`, `PATCH`, dan `DELETE` pada `../app/admin_ads.py`:

```python
from pydantic import BaseModel, HttpUrl
from datetime import date

class AdCreateUpdate(BaseModel):
    title: str
    image_url: str
    target_url: str
    platform: str = "Website"
    ad_type: str = "Banner"
    position: str = "Top"
    start_date: date
    end_date: date
    is_active: bool = True

@router.post("", status_code=status.HTTP_201_CREATED)
def create_ad(payload: AdCreateUpdate, context: AuthenticatedContext = Depends(get_admin_context)):
    res = context.database.table("advertisements").insert(payload.model_dump(mode="json")).execute()
    return {"data": res.data[0] if res.data else None}

@router.patch("/{ad_id}")
def update_ad(ad_id: int, payload: dict, context: AuthenticatedContext = Depends(get_admin_context)):
    res = context.database.table("advertisements").update(payload).eq("id", ad_id).execute()
    return {"data": res.data[0] if res.data else None}

@router.delete("/{ad_id}")
def delete_ad(ad_id: int, context: AuthenticatedContext = Depends(get_admin_context)):
    context.database.table("advertisements").delete().eq("id", ad_id).execute()
    return {"message": "Iklan berhasil dihapus."}
```

### Solusi 6: Pola Direct Upload untuk Rilis APK Android (Memperbaiki BUG-009)
Gunakan `@vercel/blob/client` pada modal upload APK untuk melewati batasan 4.5 MB pada Vercel Serverless Function:

```javascript
import { upload } from "@vercel/blob/client";

async function handleApkUpload(file) {
  const blob = await upload(file.name, file, {
    access: "public",
    handleUploadUrl: "/api/admin/upload-apk-token", // Endpoint penghasil presigned token
  });
  return blob.url;
}
```
Ini memungkinkan admin mengunggah berkas APK berukuran 20-50 MB secara instan langsung dari browser ke Vercel Blob Storage.
